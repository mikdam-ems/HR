# Decisions

Lasting decisions about how the app counts hours, leave and pay, and how it is built, each with the reason and the
date. When someone asks "why does it work like this?", the answer is here.

Add one when a choice would be hard to reverse or surprising later, usually from a research issue or a pull request.
Copy the shape of the existing ones: **Context** (the situation), **Decision** (what we chose), **Consequences** (what
follows, good and bad). Number them in order. A decision is never edited to mean something else; a new one replaces it
and says so.
