# Kadr fonts

All free from Google Fonts under the SIL Open Font License, so they can be used in the product, in print and
in documents, and shared with agencies.

| Role | Family | Weights used | Download |
|---|---|---|---|
| Headlines, wordmark | **Archivo** (variable, width axis) | ExtraBold 800 at 104–112% width | [fonts.google.com/specimen/Archivo](https://fonts.google.com/specimen/Archivo) |
| Arabic headlines | **Noto Kufi Arabic** | Bold 700, ExtraBold 800 | [fonts.google.com/noto/specimen/Noto+Kufi+Arabic](https://fonts.google.com/noto/specimen/Noto+Kufi+Arabic) |
| Interface and body | **IBM Plex Sans** | Regular 400, Medium 500, SemiBold 600 | [fonts.google.com/specimen/IBM+Plex+Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) |
| Arabic interface and body | **IBM Plex Sans Arabic** | Regular 400, Medium 500, SemiBold 600 | [fonts.google.com/specimen/IBM+Plex+Sans+Arabic](https://fonts.google.com/specimen/IBM+Plex+Sans+Arabic) |
| Hours, data, labels | **IBM Plex Mono** | Medium 500 | [fonts.google.com/specimen/IBM+Plex+Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) |

In Figma, set Archivo's **width** to 112 for the wordmark look (Text → Variable font settings).

When a brand font isn't available (Office documents, email): Arial Black for headlines, Arial or Segoe UI for
text, and Tahoma for Arabic.

The logo files in `../logo` have their lettering converted to shapes, so they don't need any of these fonts.
